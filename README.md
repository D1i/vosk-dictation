# Vosk Dictation — голосовой ввод в любое поле (Windows)

Кликните в любое поле ввода → нажмите **Ctrl+Space** → сверху появится значок
микрофона → говорите. Речь распознаётся **локально** моделью
[Vosk](https://alphacephei.com/vosk/) (без интернета) и сразу печатается в
активное окно. Ещё раз **Ctrl+Space** — выключить.

## Установка

1. Запустите `install.bat` (двойной клик).
   Скрипт сам:
   * найдёт Python 3.9+ (или скачает Python 3.12 через `uv`, если Python нет);
   * создаст окружение `.venv` и поставит `vosk`, `sounddevice`, `pystray`, `Pillow`;
   * скачает русскую модель `vosk-model-small-ru-0.22` (~45 МБ) в `models\`;
   * проверит распознавание на `tests\test_ru.wav`;
   * добавит ярлыки на рабочий стол и в меню «Пуск», автозапуск при входе в Windows;
   * запустит приложение (значок микрофона в трее).
2. Если Windows спросит про доступ к микрофону — разрешите.
   Проверить: *Параметры → Конфиденциальность и защита → Микрофон →
   «Разрешить классическим приложениям доступ к микрофону»*.

Ярлыки заново: `create_shortcuts.bat` (рабочий стол + «Пуск») или пункт
«Ярлык на рабочем столе» в меню значка в трее.

Удаление: `uninstall.bat` (убирает автозапуск и ярлыки), затем удалите папку.

## Установщик и переносимая версия

Готовые сборки лежат в `dist\`:

* `VoskDictation-1.0.0-setup.exe` — установщик: ставит программу в
  `%LOCALAPPDATA%\Programs\Vosk Dictation` без прав администратора, создаёт
  ярлыки, автозапуск и запись в «Параметры → Приложения» (там же удаление).
  Тихая установка: `setup.exe /S [/NODESKTOP] [/NOSTARTMENU] [/NOAUTOSTART] [/D=папка]`.
* `VoskDictation-1.0.0-portable.zip` — переносимая версия: распаковать в любую
  папку с правом записи и запустить `Vosk Dictation.exe`.

Обе сборки самодостаточны: внутри встроенный Python 3.12.10 с python.org
(подписи Python Software Foundation проверяются при загрузке), пакеты и модель —
на другом компьютере ничего ставить не нужно, интернет, ключи и учётные записи
не требуются (Windows 10/11 x64). Файлы не подписаны, поэтому скачанный
установщик Windows SmartScreen встретит окном «Система Windows защитила ваш
компьютер» → «Подробнее» → «Выполнить в любом случае». Контрольные суммы —
`dist\SHA256SUMS.txt`.

Сборка заново:

1. `tools\fetch_python.bat` — скачает встраиваемый Python в `build\`
   (проверяет MD5 с python.org и подписи Python Software Foundation);
2. `python tools/build_dist.py --makensis <путь к makensis>` (NSIS 3; на Linux
   с `NSISDIR=...`, на Windows — `tools\build_dist.bat`). Пакеты берутся из
   `.venv` (или `--uv`), модель — из `models\`. На медленной машине можно по
   шагам: `--stage-only`, затем `--reuse-stage --skip-installer` (архив) и
   `--reuse-stage --skip-zip` (установщик);
3. `tools\test_installer.bat` — тихая установка в `build\test-install`,
   проверки и удаление (ярлыки и автозапуск пользователя не трогаются).

## Как пользоваться

| Действие | Как |
|---|---|
| Включить / выключить микрофон | **Ctrl+Space** (или клик по значку в трее) |
| Выключается сам | после 30 с без речи (`auto_stop_silence_sec`) |
| Меню | правый клик по значку в трее: настройки, автозапуск, журнал, выход |

Текст вставляется по фразам — как только вы делаете короткую паузу.
Пока фраза не закончена, она видна в плашке сверху.

Вставка идёт через буфер обмена (Ctrl+V): так текст одинаково надёжно попадает
в любые программы. Прежнее содержимое буфера (текст, картинки, файлы)
сразу возвращается на место, а продиктованное не попадает в журнал Win+V.

### Голосовые команды

| Скажите | Получится |
|---|---|
| «точка», «запятая», «двоеточие», «точка с запятой» | `.` `,` `:` `;` |
| «вопросительный знак», «восклицательный знак», «многоточие» | `?` `!` `…` |
| «тире», «дефис» | ` — `, `-` (кто-то) |
| «открыть скобку» / «закрыть скобку» | `(` `)` |
| «открыть кавычки» / «закрыть кавычки» | `«` `»` |
| «новая строка», «новый абзац» | перенос строки (вставляется как текст — в чатах сообщение не отправится) |
| «точка ру», «точка ком» | `.ru`, `.com` |

Заглавная буква ставится в начале каждой диктовки и после `. ! ?`.
Когда микрофон выключается, после текста ставится пробел, чтобы следующая
диктовка не слиплась с предыдущей.
Выражения вроде «точка зрения», «точка доступа» не превращаются в знак.

## Запись разговора в текст (Discord и не только)

Кроме диктовки программа умеет записывать разговор в текстовый лог: распознаёт
звук, который слышно из динамиков (все собеседники), и ваш микрофон, и
складывает реплики в файл `logs\talks\<дата>_<канал>.txt` в виде

```
[21:30:05] Аня: привет, как дела
[21:30:09] Я: да нормально, работаю
```

Управление — в меню значка в трее, пункт **«Запись разговора»**: начать/остановить,
включить автозапуск при входе в голосовой канал, открыть папку логов, настроить
Discord. Можно задать горячую клавишу в `config.json` (`talk_hotkey`).

### Ники из Discord

Чтобы реплики собеседников подписывались их никами, программа спрашивает у
запущенного Discord, кто и когда говорит (звук она при этом берёт из динамиков, а
не из Discord). Нужно один раз создать своё бесплатное приложение Discord и
вписать `discord_client_id` и `discord_client_secret` в настройки — пошаговая
инструкция открывается из меню «Запись разговора» → «Настроить Discord», или
файл `Discord — настройка.txt`. Доступ только на чтение, всё остаётся на вашем
компьютере. Без Discord запись тоже работает — собеседники будут подписаны как
«Собеседник», ваши реплики — «Я».

Зайдите в голосовой канал — запись начнётся сама (пункт «Начинать при входе в
голосовой канал» включён по умолчанию), выйдете — лог сохранится.

Проверить запись звука из динамиков без Discord:
`.venv\Scripts\python.exe app\main.pyw --loop-test` (включите музыку/голос).

**Важно:** записывать разговоры можно не везде и не всегда законно —
предупреждайте собеседников и соблюдайте правила сервера и законы вашей страны.
Точность падает, когда несколько человек говорят одновременно.

## Настройки — `config.json`

Открывается из меню значка в трее → «Настройки». После правки выберите
«Применить настройки» (или просто начните новую диктовку — файл перечитается).

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `hotkey` | `ctrl+space` | Горячая клавиша (`ctrl+alt+d`, `f9`, `win+shift+s`…) |
| `model_path` | `models/vosk-model-small-ru-0.22` | Папка модели |
| `input_device` | `null` | Микрофон: `null` — системный, число — индекс, строка — часть названия |
| `auto_stop_silence_sec` | `30` | Авто-выключение после тишины (0 — никогда) |
| `typing_method` | `clipboard` | `clipboard` — вставка через буфер обмена, `unicode` — посимвольный ввод |
| `paste_keys` | `ctrl+v` | Чем вставлять: `ctrl+v` или `shift+insert` |
| `per_app_typing` | `{}` | Способ для отдельных программ, напр. `{"mintty.exe": "unicode"}` |
| `newline_key` | `shift+enter` | Только для `unicode`: чем печатать «новую строку» — `shift+enter` или `enter` |
| `voice_punctuation` | `true` | Голосовые знаки препинания |
| `capitalize` | `true` | Автоматические заглавные буквы |
| `space_after_dictation` | `true` | Пробел после текста при выключении микрофона — следующая диктовка не слипнется |
| `sounds` | `true` | Короткий звук при включении/выключении |
| `show_partial_text` | `true` | Показывать распознаваемый текст в плашке |
| `replacements` | `{"гитхаб": "GitHub"}` | Свои замены слов и фраз |
| `log_text` | `false` | Писать распознанный текст в журнал (для отладки) |
| `talk_autostart_on_channel` | `true` | Начинать запись разговора при входе в голосовой канал Discord |
| `talk_record_mic` | `true` | Записывать и свой микрофон (ваши реплики) |
| `talk_output_device` | `null` | Динамики для записи собеседников (часть названия или `null`) |
| `talk_input_device` | `null` | Микрофон для записи (часть названия или `null`) |
| `talk_merge_gap_sec` | `6` | Склеивать подряд реплики одного человека, если пауза меньше, сек |
| `talk_hotkey` | `""` | Горячая клавиша «начать/остановить запись разговора» |
| `discord_client_id` | `""` | ID вашего приложения Discord (для подписи реплик никами) |
| `discord_client_secret` | `""` | Client Secret того же приложения Discord |

Список микрофонов: `.venv\Scripts\python.exe app\main.pyw --list-devices`.

### Более точная модель

Большая модель `vosk-model-ru-0.42` (1.8 ГБ) заметно точнее, но требует
несколько ГБ памяти и дольше загружается. Скачайте и распакуйте её в `models\`
с [alphacephei.com/vosk/models](https://alphacephei.com/vosk/models) и укажите
`"model_path": "models/vosk-model-ru-0.42"`.

## Если что-то не так

* **Ctrl+Space больше не работает в IDE (автодополнение)** — горячая клавиша
  глобальная. Поменяйте `hotkey`, например на `ctrl+alt+space` или `f9`.
* **Текст не печатается в окно, запущенное от администратора** — Windows
  блокирует ввод в такие окна из обычных программ. Запустите Vosk Dictation
  тоже от администратора или не используйте его в таких окнах.
* **В какой-то программе Ctrl+V не вставляет** (например, Git Bash/mintty) —
  добавьте её в `per_app_typing` со способом `unicode` или смените `paste_keys`
  на `shift+insert`. Посимвольный ввод (`unicode`) не используется по умолчанию:
  новый Блокнот Windows 11 искажает такой ввод (повторяет одну букву).
* **Проверка способов ввода** — `tests\typing_test.bat`, затем за 4 секунды
  кликнуть в нужное окно; результат — в окне и в `logs\typing_test.log`.
* **Не слышит** — проверьте микрофон по умолчанию в Windows или задайте `input_device`.
* **Подробный журнал** — `logs\app.log`, или запустите `run_debug.bat`
  (лог в консоли).
* **Диагностика** — `diagnose.bat`: версии, список микрофонов, проверка
  микрофона и распознавания; отчёт в `logs\diagnose.txt`.
* **Демо без микрофона** — `tests\wav_demo.bat`: приложение «слышит»
  тестовую запись вместо микрофона. Вернуть обычный режим — `restart.bat`.
* **Перезапуск** — `restart.bat` закрывает запущенную копию и запускает заново.

## Командная строка

```
.venv\Scripts\pythonw.exe app\main.pyw            обычный запуск
.venv\Scripts\python.exe  app\main.pyw --console  с логом в консоли
.venv\Scripts\python.exe  app\main.pyw --selftest tests\test_ru.wav
.venv\Scripts\python.exe  app\main.pyw --mic-test     проверить микрофон
.venv\Scripts\pythonw.exe app\main.pyw --toggle   вкл/выкл в запущенной копии
.venv\Scripts\pythonw.exe app\main.pyw --quit     закрыть запущенную копию
```

`--toggle` удобно повесить на кнопку мыши или макро-клавишу.

## Устройство

```
app/main.pyw     запуск, логика вкл/выкл, одна копия приложения
app/engine.py    микрофон (sounddevice) + распознавание (Vosk) в фоне
app/textproc.py  знаки препинания, заглавные буквы, пробелы, замены
app/typer.py     ввод текста в активное окно (буфер обмена / SendInput)
app/overlay.py   плашка сверху: не забирает фокус и пропускает клики
app/painter.py   отрисовка плашки (Pillow)
app/hotkey.py    глобальная горячая клавиша (RegisterHotKey / хук)
app/tray.py      значок в трее, автозапуск, ярлык, меню записи разговора
app/recorder.py  запись разговора: звук динамиков + микрофон -> лог по никам
app/rpc.py       Discord RPC: кто в голосовом канале и кто говорит
app/diarize.py   привязка реплик к говорящему и запись лога
packaging/       сценарии NSIS (установщик, запускатель) и файлы сборки
tools/           сборка dist, загрузка встроенного Python, проверка установщика
```
